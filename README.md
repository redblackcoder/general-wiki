# General — Wiki

Catch-all for learning material without a dedicated topic wiki — search ranking, LLM inference, messaging & stream processing, consensus, algorithms, Go

Synthesized knowledge pages maintained by LLM. Also an Obsidian vault.

## Categories

Categories emerge organically as content is ingested.

## How this works

1. Raw materials go into the sibling [general-raw](https://github.com/redblackcoder/general-raw) repo
2. `/extract` produces source extracts in `sources/`
3. `/update-wiki` synthesizes extracts into wiki pages in `wiki/`
